Un sandbox que

Un espacio efímero para que un agente ejecute JavaScript vía HTTP — aislado de verdad en un intérprete QuickJS compilado a WASM, con memoria persistente en D1. Sin login, sin Docker. wrangler deploy --temporary lo levanta en segundos y desaparece solo en ~1 hora.

Por qué existe

Un agente necesita un lugar seguro para probar código

Cloudflare bloquea `eval`/`new Function` en producción, y su alternativa oficial (Dynamic Workers) requiere plan pago. La única forma real de dar aislamiento en una cuenta gratuita/temporal es correr un intérprete completo compilado a WASM adentro del propio Worker.

⚡

Cero fricción

Sin crear cuenta, sin login, sin Docker. Un comando y tenés un endpoint HTTP listo para tu agente.

🔒

Aislamiento real

No es una lista negra de nombres bloqueados — el código corre en un QuickJS-WASM que directamente no tiene fetch ni acceso a los bindings del Worker.

🧹

Se limpia solo

Nada que recordar borrar. Pasada la hora, Cloudflare elimina la cuenta temporal y todo lo que contiene.

Funcionalidades

Lo justo para que un agente ejecute y recuerde

API HTTP simple: una sesión por token, un Durable Object propio, y una D1 compartida para memoria.

🧩

Ejecución aislada

JavaScript corriendo dentro de QuickJS compilado a WASM, no vía eval del Worker.

🚫

Sin red desde el código

typeof fetch adentro del sandbox devuelve undefined — no hay APIs de red para empezar.

⏱️

Protección contra loops infinitos

Corta por pasos de intérprete, no por deadline — un while(true){} se corta en ~1-2 segundos.

🗂️

Historial por sesión

Cada ejecución queda guardada en el SQLite propio de esa sesión — código, resultado, logs y errores.

💾

Memoria con D1

Una base D1 real, auto-provisionada al desplegar, para que el agente guarde datos entre pasos y entre sesiones.

🌐

API HTTP simple

POST /new, POST /exec, POST /db/query — nada que aprender, cualquier agente lo llama con fetch.

Cómo funciona

De cero a ejecutando código en menos de un minuto

Cloná el repo

No hace falta tener cuenta de Cloudflare ni estar logueado.

git clone https://github.com/MauricioPerera/wrangler-ephemeral-sandbox.git cd wrangler-ephemeral-sandbox && npm install

Desplegá con --temporary

Wrangler crea una cuenta desechable, provisiona la D1 sola, despliega el Worker y te da la URL pública.

npx wrangler deploy --temporary

Creá una sesión y ejecutá

Tu agente hace POST /new una vez, y después POST /s/<token>/exec con el código a correr.

curl -X POST $URL/s/<token>/exec \ -d '{"code":"return 21*2"}'

¿Te gustó? Quedátelo

Wrangler también te da una claim URL. Abrila y logueate antes de que venza la hora y el Worker pasa a tu cuenta real, para siempre. Si no hacés nada, se borra solo.
